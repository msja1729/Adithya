SMRITI: Memory Firewall for AI Agents

Team Lead (4 members)
AEGIS 2026, IISc Bengaluru
48% → 0/60attack success
100%clean-task completion
0false rollbacks
  • Built a provenance-based security layer that protects LLM agents from memory-poisoning attacks, where stored malicious text triggers harmful actions (e.g., fraudulent payments) weeks later.
  • Designed three checkpoints: a write gate (source-based trust labels, quarantine of instruction-like untrusted text, PII redaction), a read gate that admits only trusted memory into agent instructions, and an action check requiring human approval for risky actions to unknown destinations.
  • Created MemPoison-Bench (3 agents × 4 attack types × 5 seeds): cut attack success from 48% to 0/60, vs. 23% for NVIDIA NeMo Guardrails, with 100% clean-task completion and no measurable added latency.
  • Built a counterfactual Immune Auditor that replays past requests to trace a harmful action to its source memory, then rolls back that memory and everything derived from it, with 0 false rollbacks.
  • Formally verified core guarantees in Lean 4 (no trust escalation; summaries inherit the lowest input trust), backed by 460+ unit tests and differential testing against the proofs.
